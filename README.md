# BlockEdu — Premium Web3 Sandbox Lab Ecosystem

BlockEdu is an immersive, production-grade Web3 educational simulation framework engineered completely within client-side browser space. The architecture provides intuitive visual interactions with peer-to-peer ledger mechanics, asymmetric verification states, and real-time network streams.

---

## 🛠 Technical Implementation Stack

| Layer Element         | Engine Framework                        | Architecture Purpose                                                  |
| :-------------------- | :-------------------------------------- | :-------------------------------------------------------------------- |
| **Interface Mapping** | Bootstrap 5.3 + Custom Glass Primitives | Clean responsive views across all layout containers                   |
| **Cryptography**      | Asynchronous Web Crypto API             | High-performance SHA-256 local mining verification                    |
| **Data Engine**       | CoinGecko Public Interface              | Asynchronous market query mapping with integrated rate-limit handling |
| **Logic Layer**       | Vanilla ES6 JavaScript                  | Framework-agnostic processing handling client tasks natively          |

---

## 🚀 Hackathon Core Parameter Checklist

### 1. Visual Mastery (Premium Experience Layer)

- Designed around a **unified luxury dark-mode ecosystem** leveraging consistent global variable maps (`--bg-darkest`, `--accent-purple`, `--border-glass`).
- Employs responsive text sizing maps to prevent viewport overflow or broken block lines on mobile profiles.
- Features clear, structured design separation between the app views and components (such as the `#05050a` footer background boundary).

### 2. Engineering Architecture & Integrity

- **Zero Heavy External Dependencies:** Relies on native web features rather than heavy alternative framework libraries, leading to faster execution times.
- **Robust Error Context Boundaries:** `prices.js` includes clear conditional interface feedback components to notify users if the public endpoint rate threshold is hit, preventing the UI from freezing.
- **Accurate Mathematical Avalanche Propagation:** Changing an input string signature inside the simulator instantly updates and flags downstream dependencies as tampered or unmined.
